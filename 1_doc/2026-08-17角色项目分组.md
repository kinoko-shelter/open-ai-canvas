# 创作页项目选择
`GET /api/aigc/projects/available/tree` 用于 `/create` 文本创作、图片生成、视频生成参数栏，以及短剧创作和画布的新建/设置页的项目树选择。接口返回一级项目 + 二级项目树，一级、二级都可选；管理员看全部可用项目，非管理员只看启用的一级项目和本团队的启用二级项目。该接口只读，不要求项目管理角色权限。

# 文本创作 进的表：
文本创作 不进 tasks 表，创作状态存浏览器本地；若走系统代理，计费会落 billing_orders / credit_ledger_entries。
图片生成/视频生成 进 tasks 表


计费相关主要是这几张表：

billing_orders：计费订单/预授权记录。创建请求时先生成订单，状态从 reserved/running 到 settled/refunded/uncertain；新记录使用 aigc_project_id 记录创作页选择的运营项目。
credit_ledger_entries：积分流水，也就是“消费历史”。里面会有 reserve 预冻结、consume 实际消费、refund 退款等记录；新计费相关流水继承 billing_orders.aigc_project_id。
credit_accounts：用户积分账户余额，包含可用积分和冻结积分。
