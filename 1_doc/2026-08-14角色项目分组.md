# 概述
1. 创建 角色表 aigc_role
2. 创建 部门表 aigc_department
3. 创建 项目表 aigc_project

注意,下面说的 sys_ 开头的表都属于 mars_kol

# 用户表改造
users 里加个字段 sys_user_id  记录 mars_kol 里的 user_id , 至此,用 sys_user_id 将 本系统和 kol 系统关联起来

登录改造:增加 KOL系统登录,实现一个 
login_from_kol(kol_token) 接口. kol_token 是 KOL系统的分发token ,可以用这个token 调用 kol的认证接口 得到用户 角色等信息
随后, 检查用户ID是否存在: 1.不存在时 将 kol 里的用户新拉回来放到 users 表里,并记录 sys_user_id; 2.已存在,则 认为登录成功,进入首页.

# 角色表
sys_role
sys_user_role, 用 user_id, 和 role_id 表达 角色和用户的多对多关系
