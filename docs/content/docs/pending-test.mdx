# 待验证

- 结算单：运营管理或管理员账号应能在工作台管理菜单看到 `/settlement-statements`；页面默认展示当前月份结算单并显示结算单 ID，支持月份、团队、项目、状态筛选；未分配团队的消费应按个人分别展示；查看应进入消费明细并带入月份、团队/个人、项目和结算类型；确认和批量确认应仅处理未结算结算单并刷新状态；后台应每 20 分钟刷新当月未结算快照，每月 1 号额外刷新上月，已结算快照不得再被刷新覆盖。
- 系统渠道计费的前台模型选择器：模型列表应展示渠道规格价格范围；选中视频模型后，分辨率和时长命中的价格档应显示实际积分。未配置有效价格档的模型应显示“未配置”，不得显示泛化的“按渠道计费”。
- 前台模型开关：关闭后创作端应从 `/api/model-catalog` 切换到脱敏的已启用系统渠道目录；管理员仍能访问模型配置并重新启用。旧逻辑模型选择、新目录外的渠道模型和无有效 SKU 价格的请求必须被任务创建接口拒绝；用户自定义渠道不受此开关影响。
- 系统渠道 SKU：图生视频在参考图数量、分辨率和时长变化时，应命中相应价格档；任务账单、供应商模型键和创作端价格展示必须使用同一档位。
- 画布媒体与提示词：历史竖图首次加载应按真实比例校正节点，手工拉伸、自由比例和锁定节点不得被改写；无参考图的视频提示词卡不应出现首帧/尾帧控件，已有多行提示词加载后高度应与内容匹配。
- `sync-channel-fallback`：在 PostgreSQL 环境先执行 dry-run，再以 `AI_WAVE_API_KEY` 执行 `--apply`；确认主渠道的模型、规格价格和前台模型备用线路均被同步，且重复执行不会新增重复线路。
- 逻辑模型备用路由：主线路返回未携带供应商任务 ID 的 503 时，应在 30 秒熔断窗口内切换到低优先级备用线路；前台模型管理页应展示系统规格价格并提供新增、编辑、启停和归档操作。
- 方舟可信素材：在 PostgreSQL 环境配置 IAM `ark:*Asset*` 权限的 AK/SK 后，使用当前用户素材库中的图片创建方舟 Seedance 视频；首次应创建素材组、导入并轮询到 `Active` 后以 `asset://` 提交，第二次同图同 Ark Project 应命中绑定缓存且不重复上传。画布图片节点的“更多 → 上传到方舟素材库”应先要求操作者确认拥有使用权，对尚未入库的图片先保存为当前团队可读素材，再完成同一审核与绑定流程。关闭“自动同步可信素材”时应保留原有参考图传参；审核失败或超时必须失败任务，不得回退到原始 URL。
